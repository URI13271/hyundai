# Ruby로 화면을 만드는 공부

이 폴더는 드라이브 토크 코드를 교재로 쓴다. 목표는 두 가지다. Ruby 문법을 이 파일들에서 읽고, 다음 앱도 같은 방식으로 화면부터 만들 수 있게 되는 것.

브라우저 안에서 Ruby가 도는 구조는 아니다. Ruby는 서버에서 HTML을 만들어 보내고, 브라우저가 그 HTML을 그린다. 앞으로 Ruby를 프론트로 쓴다는 말은 이 뜻이다.

워드 파일 대신 마크다운으로 둔 이유는 깃에서 고친 줄이 보이고, GitHub에서 그대로 읽히기 때문이다.

## 앱을 띄우고 읽기

Ruby 3.2 이상이 필요하다. `Data.define`이 3.2부터 있다.

```sh
ruby bin/drive_talk
```

브라우저에서 `http://127.0.0.1:4567/?demo=1` 을 연다. `demo=1`은 마이크 창을 건너뛴다.

고칠 때 재시작이 필요한지부터 구분한다.

| 고친 파일 | 재시작 |
| --- | --- |
| `views/screen.erb`, `public/app.css`, `public/adaptive.css`, `public/app.js` | 필요 없다. 새로고침 |
| `lib/`, `bin/` | 필요하다. 서버를 끄고 다시 실행 |

화면 파일은 요청마다 디스크에서 다시 읽는다. `server.rb`는 프로세스가 켜질 때 한 번 읽는다.

## 이 교재가 일부러 하지 않은 것

Rails, Sinatra, 데이터베이스, 진짜 음성 인식은 없다. 없는 이유는 화면이 만들어지는 길이 가려지지 않게 하려는 것이다. 그 길만 보이면 나중에 프레임워크를 얹는 일이 쉽다. 얹는 시점은 [07-다음-앱.md](07-다음-앱.md)에 있다.

덱을 파일로 빼고, 판을 저장하고, 말을 선택으로 바꾸는 계약은 공부 문서가 아니라 [BACKEND.md](../../BACKEND.md)다.
